    source [2] MongoDB compound index docs
    source [3] indexing-report.pdf  /  Query plans
    source [4] indexing-report.pdf  /  Results
  answer: A compound index only helps when the query's fields are a prefix of it, in that order [1]. For example, an index on (a, b) helps a query on a, and on a with b, but not on b alone [2].
