    source [1] Database indexing exercise
    source [2] MongoDB compound index docs
    source [3] indexing-report.pdf  /  Query plans
    source [4] indexing-report.pdf  /  Results
  answer: Compound indexes only help when the query's fields are a prefix of the index, in that exact order [1]. For example, an index on fields a and b helps a query on a, and on a with b, but it does not help a query on b alone [2]. Similarly, a compound index that begins with author cannot be used by a query on the second field alone due to this prefix rule [3].
