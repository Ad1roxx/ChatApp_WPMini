    source [1] Database indexing exercise
    source [2] MongoDB compound index docs
    source [3] indexing-report.pdf  /  Query plans
    source [4] indexing-report.pdf  /  Results
  answer: A compound index helps when the query's fields are a prefix of it in that order [1]. According to the prefix rule, an index on fields a and b helps a query on a, and on a with b, but not on b alone [2]. For example, a compound index that begins with author cannot be used by a query on the second field alone [3].
